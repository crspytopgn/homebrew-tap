# OpenSGolf Homebrew tap

```sh
brew install --cask crspytopgn/tap/opensgolf
```

OpenSGolf is a free, open source engine for the golf course building game SimGolf: https://github.com/crspytopgn/opensgolf

If you enjoy OpenSGolf, you can [sponsor me on GitHub](https://github.com/sponsors/crspytopgn) or [buy me a coffee](https://buymeacoffee.com/crspytopgn).
